# Use when

Use this skill when writing UI copy, choosing visual treatments, designing new sections, or evaluating whether a design decision feels on-brand.

# Brand in one sentence

Madinaty AI is the intelligent, warm, and playful AI layer over Madinaty — Egypt's largest smart city — built for a community of 700,000+ residents across 23 districts.

# Personality adjectives

**Smart** — precise, data-driven, never vague  
**Warm** — community-first, family-friendly, inclusive  
**Playful** — Astro the robot dog, bright colors, micro-delights  
**Trustworthy** — affiliated with TMG, real services, real data  
**Local** — Madinaty-specific, not generic AI chatbot  

# Visual personality

| Trait | Expression |
|---|---|
| Bright optimism | Sunny Horizon palette — teal, coral, sun yellow on light backgrounds |
| Tech depth | Aurora Night dark theme — deep navy, electric teal glows |
| Warmth | Coral CTA buttons, warm gradient backgrounds |
| Intelligence | Glassmorphic surfaces, precise grid, Space Grotesk headings |
| Playfulness | AstroAvatar animations, confetti, count-up stats, orb floats |

# Visual metaphors

- **Morning sky over Madinaty** — warm sunrise palette, bright hero backdrops
- **AI intelligence layer** — teal glows, visor effects, circuit-like grid overlays
- **Community hub** — card grids showing services side by side, bento layouts
- **Smart city** — map integration, live data pulses, animated stat strips

# Copy voice

**DO:**
- Short, confident sentences
- Action-first CTAs ("اكتشف", "ابدأ", "Explore", "Get started")
- Warm second person ("لسكان مدينتي", "for Madinaty residents")
- Specific numbers and benefits ("700,000+ residents", "23 districts")
- Arabic-first when addressing the community

**DON'T:**
- Corporate jargon ("leverage synergies", "empower stakeholders")
- Vague AI hype ("revolutionary", "next-generation", "cutting-edge")
- Formal Egyptian Arabic that feels bureaucratic
- Long paragraphs (max 2–3 lines per body text block)
- Generic city/tech stock imagery descriptions

# Forbidden clichés

These visual and copy patterns are **off-brand** — never use them:

| Cliché | Why it's forbidden |
|---|---|
| Generic blue SaaS gradient hero | Too generic, not Madinaty |
| "We're revolutionizing X" copy | Vague hype |
| Purple AI glow everywhere | Not our palette |
| Stock photo of smiling people with laptops | Impersonal |
| Generic chat bubble icon for AI | Use AstroAvatar instead |
| White card grid with identical blue CTAs | No personality |
| "Powered by AI" as a standalone feature | Meaningless |
| Skeleton-only loading with no character | Use Astro thinking state |

# Differentiation rules

1. **AstroAvatar is the AI face** — always. Never a faceless bot icon.
2. **Arabic is primary** — RTL-first, Cairo/Alexandria fonts, natural Arabic copy.
3. **Madinaty-specific content** — district names, TMG services, real city data.
4. **Two themes with personality** — Sunny Horizon is not just white; Aurora Night is not just dark.
5. **Warm accents** — coral and sun appear alongside teal to avoid clinical cold-tech feel.

# Section writing template

```
[Overline label — 2–4 words, teal, uppercase]
[Heading — 4–8 words, bold, benefit-first]
[Subheading — 1–2 sentences max, --text-soft, max 52ch]
[CTA — verb + object, e.g. "Start Chatting" / "ابدأ المحادثة"]
```

# Tone by context

| Context | Tone |
|---|---|
| Hero section | Confident, inspiring, bold |
| Feature card | Clear, benefit-focused, concise |
| Chat / AI response | Warm, helpful, conversational |
| Error message | Calm, never alarming, always offer a next step |
| Success / celebration | Enthusiastic, human, emoji-optional |
| Onboarding | Friendly guide, not instruction manual |
| Empty state | Inviting, not apologetic |
